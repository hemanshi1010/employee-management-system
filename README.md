# Employee Management System

## Overview

The Employee Management System is a web-based application developed using HTML, CSS, JavaScript, and Bootstrap 5. It allows users to manage employee records efficiently through features such as adding, editing, deleting, and searching employees. The application also provides real-time employee statistics and uses Local Storage to persist data across browser sessions.

## Features

* Add new employee records with Name, ID, Salary, and Gender.
* Edit existing employee details.
* Delete employee records with confirmation prompts.
* Search employees by Name or Employee ID.
* Real-time employee count and salary summary.
* Form validation to ensure accurate data entry.
* Responsive and user-friendly interface using Bootstrap 5.
* Local Storage integration for persistent data management.
* Interactive status notifications for user actions.
